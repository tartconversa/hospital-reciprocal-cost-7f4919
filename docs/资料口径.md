# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

所有费用元，服务量按type独立单位。power=kWh、laundry=kg、repair=hour，不跨类型相加。source_cost中kind=expense为已形成原生费用，payment只现金不再加，pending仅待核。service_claim双方以transfer_id明确对应，quantity不同保留争议；matched_quantity须人工核实，不能任取min当共同认可。fixed费用按capacity_share，variable按confirmed usage份额；capacity_share在provider全体消费者含IDLE合计1。fixed不因actual_use=0自动全转给有用量方。variable未服务部分按capacity中的idle_variable_share进入IDLE，余可分费用用实际确认服务量；provider对自身服务不重复消耗；internal收到的费用始终标为转入而非新原生。互供没有有效临床或IDLE吸收出口时不能确认成平衡。period为自然月；source_origin可追到每笔原生费用，内部循环不改变医院原始总额。

## later_confirmations
后续T8修正共同认可后才影响本期。

记录键：['confirmation_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| confirmation_id | string | 行 |
| transfer_id | string | 服务 |
| matched_quantity | number | 共同确认 |
| confirmed_at | datetime | 确认 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。later_confirmations为后续接收文件，不随基础资料自动生效。事实的业务期间与本次接收时点分开。金额结算到分，尾差归同一笔费用终端分摊基数最大项，并列按中心键升序；尚未吸收的成本不是可用来放尾差的科室。本文规定来源语义，不规定待开发仓表、算法或架构。

T8供方10、用方8为待核，不以9自动折中；later_confirmations的9是另行人工核实事实。固定成本按容量，所有转入成本按该中心已确认variable服务份额及闲置比例继续承担，不能再次套原始固定容量分母；原生fixed和variable标签可追到来源但转入不是新增fixed预算。不规定计算算法，任何同时符合全部责任与总额的实现均可。容量表同一provider重复列出的idle_variable_share是同一个中心级比例，不能逐行相加。服务量未全部核实时，已认可部分和未达分别可查，不能将局部核算结果当作完整期间结转确认。
